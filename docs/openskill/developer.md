# Developer

- **Id**: https://logicsrc.com/openskill/developer
- **Kind**: occupation
- **Domain**: Computing
- **Language**: en
- **Aliases**: software developer, application developer

A software-focused role that builds and maintains applications, services or other software systems.

## Includes

- Implementing and maintaining software in collaboration with its users and other contributors.
- Here the label means software developer; property and business development are separate concepts.
