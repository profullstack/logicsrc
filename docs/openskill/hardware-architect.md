# Hardware architect

- **Id**: https://logicsrc.com/openskill/hardware-architect
- **Kind**: occupation
- **Domain**: Computing
- **Language**: en
- **Aliases**: computer hardware architect, hardware systems architect

A role that defines a computing system's hardware structure and the tradeoffs between its components.

## Includes

- Architecture requirements, component boundaries and interfaces.
- Reasoning about performance, power, cost, manufacturability and verification.
