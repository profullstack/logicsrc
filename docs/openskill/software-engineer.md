# Software engineer

- **Id**: https://logicsrc.com/openskill/software-engineer
- **Kind**: occupation
- **Domain**: Computing
- **Language**: en
- **Aliases**: software engineering professional

A role that applies engineering judgment to the design, implementation, verification and evolution of software systems.

## Includes

- System design, software quality, operational constraints and lifecycle tradeoffs.
- Programming and collaboration across the system's requirements and interfaces.
